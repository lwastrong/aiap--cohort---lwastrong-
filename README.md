# AccessAbility by LWA

**Find disability-approved hotels, restaurants, and things to do — anywhere.**

Built by [Art Thomas](https://lwastrong.com), Founder/CEO of LWA (Living With Ataxia), for the AI Accelerator Program hackathon.

## What it does

Type any address and instantly see nearby hotels, restaurants, and activities — each with a real accessibility rating pulled live from OpenStreetMap's community-reported data.

- 🟢 **LWA Approved** — verified wheelchair-accessible AND meets LWA standards (accessible restroom, or meat-first menu for restaurants)
- 🟡 **Disability Approved** — verified wheelchair-accessible
- 🟠 **Partially Accessible** · 🔴 **Not Accessible** · ⚪ **Not Verified — call ahead**

## Features

- Address search with 1 / 2 / 5 / 10-mile radius, or use your current location
- Three categories: Hotels & Stays · Where to Eat · Things to Do
- **LWA nutrition rules**: fast food, fried, dessert-first, and BBQ spots are filtered out; meat-first places (steakhouse, grill, seafood) are badged carnivore/keto-friendly
- Kid-friendly filter (real family data: kids areas, high chairs, playgrounds, zoos, parks)
- Activity search across all categories ("pool", "museum", "gym", "steak"…)
- 📸 Community Corner — post reviews with photos, no account needed
- Accessible design: large text, high contrast, keyboard-friendly

## How to run it

Download `index.html` (or `LWA-AccessAbility-App-2026-08-20.html` — same file) and double-click it. It opens in any browser. No install, no account, no API keys. Internet connection required for live place data.

## Data & honesty

Accessibility data is community-reported via OpenStreetMap and may be incomplete. "Not Verified" does not mean inaccessible — it means nobody has reported it yet. Always call ahead. This app is an informational tool, not a guarantee of access.
